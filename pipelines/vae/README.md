# VAE Notebook

`VAE_learn_mask.ipynb` is the imported mask-generation notebook from the source repository. In the merged repo it defaults to:

- `dataset/DhMurals-inpainting-dataset/train` for the training split
- `dataset/DhMurals-inpainting-dataset/train_sub` for validation
- `dataset/DhMurals-inpainting-dataset/test` for testing

Generated masks can still be exported into `dataset/VAE_generated_masks`.
